## Institutional Users
To replicate this entire webroot, clone from [REPOSITORY] to your machine. Place the clone in the web directory of your server (i.e. `http://your_IP_or_FQDN_server/ce-5319-webroot`).  Verfiy you get to the landing page, then use a string editor to global change all instances of `http://54.243.252.9/` to `http://your_IP_or_FQDN_server/`.  This should also work with `https: ... ` if you use self-signed certificates.  There are some more steps if using a proper certificate authority.  All scripts can be run on a Raspberry Pi (albeit quite slowly).
